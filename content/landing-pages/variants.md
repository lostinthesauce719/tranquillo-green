## Recommended A/B Test Order

1. **Week 1-2:** Variant A (Tax Hook) vs Variant B (Time Hook)
   - Measure: Calculator usage, demo requests
   - Expected winner: Variant A (stronger pain point)

2. **Week 3-4:** Winner vs Variant D (Audit Fear)
   - Measure: Demo requests, time on page
   - Expected winner: Depends on audience (operators vs CPAs)

3. **Week 5-6:** Winner vs Variant C (CPA Hook) — CPA traffic only
   - Measure: Partner applications
   - Expected: CPA traffic converts best on Variant C

4. **Week 7+:** Testing micro-elements on winning variant
   - CTA copy, hero image, social proof placement, form length
